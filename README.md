# 深圳闪避

深圳通勤主题的 20 秒微信小程序闪避游戏。玩家左右拖动上班族，避开外卖电动车、电摩、自行车和滑板车，在三条命耗尽前坚持到打卡点。

## 当前玩法

| 项目 | 实现 |
| --- | --- |
| 单局时长 | 最长 20 秒 |
| 初始生命 | 3 条 |
| 碰撞保护 | 每次碰撞后 1.05 秒 |
| 障碍物 | 外卖电动车、电摩、自行车、滑板车 |
| 波次 | 随机生成一辆或两辆；双车不会同时进入画面 |
| 难度 | 5 秒后缩短生成间隔，12 秒触发晚高峰阶段 |
| 场景 | 岗厦村晚霞、湖贝村雨夜、白石洲清晨 |
| 音乐 | 《深南夜行》，支持播放、静音和循环 |

道路会为玩家保留可闪避空间。滑板车可能斜向切入，自行车会轻微晃动。贴身避开车辆会累计“惊险擦身”次数。

## 操作与界面

- 在画面中左右拖动角色。
- 切到后台时，游戏和音乐会暂停。
- 暂停后继续游戏会显示 3 秒倒计时。
- 首页默认随机选择场景，也可以手动切换。
- 菜单提供继续、重新开始、场景切换、音乐开关和玩法说明。

最佳成绩和累计失败次数保存在微信本地存储中：

- `sz-commute-best`
- `sz-commute-deaths`

## 结算与分享

完成或结束一局后，可以生成包含当前游戏画面的 PNG 战报。分享界面使用微信小程序原生 `open-type="share"` 按钮，分享卡片由 `onShareAppMessage` 提供标题和图片。

累计失败 5 局后会显示分享提示。玩家可以跳过分享继续游戏；该提示不会强制转发。

## 在微信开发者工具中运行

1. 打开微信开发者工具并选择“导入项目”。
2. 选择仓库根目录。
3. 项目类型选择“小程序”。
4. 确认 AppID 为 `wx8f67c6e67c920fa4`。
5. 点击“编译”运行模拟器，或点击“预览”生成真机二维码。

项目使用竖屏布局，微信开发者工具基础库版本固定为 `3.17.1`。

## 自动化测试

本地需要 Node.js 22 或更高版本。测试不安装第三方依赖。

```bash
npm test
```

测试覆盖：

- 扫掠式碰撞检测和碰撞后的无敌时间。
- 三条命、暂停、恢复、重新开始和 20 秒胜利条件。
- 角色活动边界。
- 四类障碍物、单双车随机波次和滑板车斜切。
- 双车波次的 0.18 秒错峰进入。
- 累计失败 5 局后的可跳过分享提示。
- 30 FPS 与 60 FPS 下共 100 组带种子的自动通关模拟。
